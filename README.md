# RutaLibre

Sitio web para transporte privado en Cuba. Contiene la página principal, la lista de rutas y activos asociados.

## Estructura principal

- `index.html`: página principal.
- `rutas.html`: página de rutas y traslados.
- `css/`: estilos del sitio.
- `js/`: traducciones, navegación móvil, validación de formulario y datos de rutas.
- `assets/`: imágenes usadas por el sitio.
- `robots.txt`: instrucciones básicas para buscadores.
- `sitemap.xml`: mapa del sitio para Google/Search Console.

## Publicación

El sitio está preparado para publicarse como web estática en GitHub Pages.

URL actual:

```txt
https://pepilloagricola.github.io/rutalibre/
https://pepilloagricola.github.io/rutalibre/rutas.html
```

Al publicar, sube `index.html`, `rutas.html`, `robots.txt`, `sitemap.xml`, `css/`, `js/` y `assets/`.

No publiques archivos temporales como `Untitled-1.html`.

Cuando exista un dominio personalizado, actualiza las URLs absolutas de SEO en `index.html`, `rutas.html`, `robots.txt`, `sitemap.xml` y la firma del mensaje en `js/script.js`.
